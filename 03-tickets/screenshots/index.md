# Screenshots index — 03 Tickets

**109 images.** Captured 2026-10-23 from the running app on the carrier Acme Trucking Inc. with the Super Admin test account (Kenan Gain), and the User test account (Lily Chen) for the view-only state. Desktop = 1440 px wide, mobile = 390 px wide. Nothing is masked: every name, address, email and phone number is fictional demo data and is shown exactly as the app shows it.

**Note on the detail shots:** the demo tickets carry no documents, trailer, second violation or legal expense, so before the detail captures one demo ticket (**OFF-84729**) was filled in through the app's own ticket store with values in fields the app already has (driver Anjali Bhatia, units ACM-T0108 + ACM-TR0112, two charges, two documents, legal expense, court details). Everything else is the app's own demo data. Acme's synthesised tickets change on every page load, so counts in different shots can differ slightly (301–313).

File name pattern: `[tab]-[state]-[device].png`. The list, the detail page and the form are one route (`/tickets`); the three folders follow those three views.

## States not captured (and why)

- **Opened native `<select>` menus** (status pill, Status / Type / Document / Source filters, form selects) — they render outside the page; the result of each choice is captured.
- **Browser number-field bubble** — captured where Chromium draws it (`form-add-native-validation`); it is the browser's, not the app's.
- **OOS chip, "+N" violations and the legal-expense tooltip on the list** — no demo ticket on the list carries them except the filled-in OFF-84729 (see the note above).
- **A newly added ticket in the list** — it is saved without a carrier and does not appear in the carrier's list (page-overview §11 #6).
- **Loading state** — none exists.
- **Toasts** — none exist in Tickets.
- **"Hidden" access page** — Tickets is hidden only for drivers, who are routed to the Driver Mobile App; the page itself is the app-wide "Not in your menu" page.
