# 03 – Tickets · Colour palette

Every colour the Tickets section uses, named as tokens. **Light** values are what the app renders today: Tailwind CSS v4's default palette, converted exactly from its OKLCH definitions to sRGB. **Dark** values are a **proposal** — the app has no dark mode (no `dark:` variants, no `prefers-color-scheme` rules).

Machine-readable: [color-palette.json](color-palette.json) · Figma tokens: [figma/tokens.json](figma/tokens.json).

## WCAG 2.1 contrast

Normal text needs **4.5 : 1** (AA) or 7 : 1 (AAA); large text (≥ 18.66 px bold / 24 px) and essential UI parts need **3 : 1**.

**Failing pairs (5):** `text-muted` on `surface` (kpi sub-lines, empty dashes, placeholders); `text-muted` on `background` (muted text on the table header band); `danger` on `danger-subtle` (critical severity chip); `border` on `surface` (card / table border against the card (non-text; 3:1 only for essential ui)); `border-strong` on `surface` (form input border (non-text ui component, wcag 1.4.11 asks 3:1)).

What to do about them:
- `text-muted` (slate-400) is used for **text** on 59 class occurrences (KPI sub-lines, empty dashes, placeholders). Move every *text* use to `text-secondary` (slate-500, 4.76 : 1); keep slate-400 for icons and decorative rules only.
- `danger` text (rose-600) on `danger-subtle` is 4.12 : 1 — set pill text to rose-700 (`#c70036`, 5.49 : 1), as the Terminated pill already does.
- `border` (slate-200) is fine for card outlines, which are not essential to understanding; for **form inputs** use `border-strong` and darken it to slate-400 (`#90a1b9`, 2.63 : 1) if WCAG 1.4.11 compliance is required.

## Notes

- text-muted (slate-400) fails 4.5:1 on white and slate-50; it is used for KPI sub-lines, empty dashes and placeholders. Recommended fix: use slate-500 for any text.
- The KPI cards carry a 1.5 px coloured bar and a coloured value: Outstanding rose, Open Offenses amber, In Court indigo, Paid emerald, Electronic violet. Indigo appears only on that card — the In Court pill is blue.
- Some components mix the red and rose families for errors/danger, and green with emerald for success; the tokens above pick one family per role.
