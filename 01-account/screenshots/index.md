## States not captured (and why)

- **Delete confirmations** — the app uses the browser's native `confirm()` dialog for Delete asset / driver / yard terminal; native dialogs cannot be screenshotted. Text: `Delete <noun> <name>? This cannot be undone.`
- **Inline status dropdown opened** — native `<select>` menus render outside the page and cannot be captured; the closed pill is in the default shots.
- **Columns picker and the Drivers row ⋮ menu on mobile** — the Columns button is not rendered below the `sm` breakpoint, and the mobile driver cards open the driver directly (no row menu). The Assets row menu exists on mobile and is captured.
- **"All Assets" sub-tab reset on mobile** — the sub-tab strip scrolls; the Trucks shot is captured, the strip itself is in the default shot.
- **Loading state** — none exists (local data renders immediately).
- **No-carrier state** — TO CONFIRM: no demo login without a carrier is available; capture once one is added.
- **Toasts** — transient (auto-dismiss); their texts are listed in docs/page-overview.md §7.
