# Screenshots index — 02 Inventory

**238 images.** Captured 2026-10-23 from the running app on the carrier Acme Logistics with the Super Admin test account (Kenan Gain), the driver test account Jason Cooper for the driver-side shots and the Safety Manager test account (Marcus Reed) for the view-only state. Desktop = 1440 px wide, mobile = 390 px wide. Nothing is masked: every name, address, email and phone number is fictional demo data and is shown exactly as the app shows it.

File name pattern: `[tab]-[state]-[device].png`. Pages reached from a tab are filed under that tab (the item page under `list/`, a driver's holder page and the sign-form under `drivers/`, the vendor profile under `vendors/`).

## States not captured (and why)

- **Native browser dialogs** — none in Inventory (delete confirmations are in-app dialogs and are captured).
- **Opened native `<select>` menus** (Group by, Rows, Status, Country) — they render outside the page; the closed selects and the result of each choice are captured.
- **Loading state** — none exists (local data renders immediately).
- **Empty carrier and no-carrier states** — every demo carrier has inventory; TO CONFIRM (page-overview §12 #26).
- **Item not found / holder not found by stale id** — needs a stale record link; the holder not-found page is captured through the empty-holder defect (`drivers-holder-empty-not-found`).
- **The holder preset add form** (`/inventory/drivers/:id/add`) — nothing links to it.
- **Toasts** — none exist in Inventory.
- **"Hidden" access page** — Inventory is hidden only for drivers, who are routed to the Driver Mobile App instead; the page itself is the app-wide "Not in your menu" page described in page-overview §0.
